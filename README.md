# HERO — 삼국지 영걸전 리메이크 (YGJ-Remake)

DOS용 「삼국지 영걸전」(KOEI, 1995)의 게임 시스템과 플레이 감각을 윈도우·맥에서 실행 가능한 프로그램으로 재구현하는 개인 프로젝트.

> **개인 플레이 전용** — 배포하지 않으며, 원작 파일·에셋을 추출하거나 포함하지 않는다(하이브리드 리메이크: 엔진 신규 구현 + 커뮤니티 자료 기반 데이터 입력).

## 현재 상태

- **요구사항·설계 기준선 v1 승인** (2026-08-17)
- **M0 뼈대 완료** — 데이터 스키마·검증 파이프라인과 타일맵 렌더가 동작한다. `npm run dev`로 테스트 전장이 렌더되고 `npm run validate`가 데이터 참조 오류를 잡는다.
- 다음: M1 전투 프로토타입

## 핵심 특징 (계획)

- **원작 재현**: 턴제 전투(반격 없음), 병과 상성(보<기<궁<보, 방어 ±25%), 책략(지형·날씨 게이트), 일기토, 사실/가상 루트 분기, 원작 동일 맵(타일 단위 재현, 간략화 금지)
- **편의 개선**: 전투 중 턴 중간 세이브/로드(조조전식, RNG 상태 포함), 게임 내 장수 에디터(능력치·레벨·초상화, 사용자 오버레이 전역 적용)
- **개조 용이**: 모든 게임 콘텐츠가 `data/` JSON — 병종을 추가·수정하면 엔진 코드 수정 없이 데이터와 UI가 자동 반영. `npm run validate`로 참조 무결성 전수 검사

## 기술 스택

TypeScript(strict) · Vite · PixiJS v8(맵/유닛 렌더) · HTML+CSS DOM 오버레이(메뉴 UI) · Zustand · zod · Vitest · Tauri v2(윈도우·맥 패키징) · Howler.js

## 개발

Node.js LTS(v24 기준)가 필요하다.

```bash
npm install
npm run dev       # 브라우저에서 실행 (http://localhost:5173)
npm run validate  # 데이터 스키마·참조 무결성 전수 검사 (문제 시 exit 1)
npm test          # 코어 로직 단위 테스트 (Vitest)
npm run build     # 타입 검사 + 프로덕션 빌드
```

`npm run validate -- <경로>`로 임의의 데이터 폴더를 검사할 수도 있다.

### 데이터 개조

게임 콘텐츠는 전부 [data/](./data/)의 JSON이며 엔진은 이를 해석만 한다. 병과·지형·상성·스프라이트 매핑을 고친 뒤 `npm run validate`로 참조 누락을 확인하면 된다. 스프라이트 시트가 없는 항목은 플레이스홀더 색으로 렌더되므로 그래픽 없이도 시스템을 완성할 수 있다.

## 저작권 고지

원작 「삼국지 영걸전」의 저작권은 KOEI(현 코에이 테크모)에 있다. 본 저장소는 원작 게임 파일·에셋을 포함하지 않으며, 개인 학습·플레이 목적으로만 사용한다. 원작 대조용 개인 참고 자료(`reference/`)는 git에서 제외한다.
